# Public API — OpenAPI spec

`openapi.json` in this directory is a standalone export of the SC Companion
public API spec, intended for upload to [readme.io](https://readme.io) (or
any other OpenAPI-driven docs tool).

## Single source of truth

The canonical spec lives in code: `supabase/functions/api/openapi.ts`
(`export const SPEC`). The live `/openapi.json` endpoint served by the edge
function always reflects that file directly.

`docs/api/openapi.json` was generated by evaluating `SPEC` from
`openapi.ts` (with the `errorRef()` helper calls resolved to their literal
output) and serializing the result with 2-space indentation. It is **not**
auto-regenerated on every change to `openapi.ts` — there is no CI step or
watch process wired up yet.

## Keeping it in sync

Whenever `supabase/functions/api/openapi.ts` changes:

1. Re-export `docs/api/openapi.json` (either re-run the extraction approach
   used to generate it — load the file, strip the Deno-only `import type`
   line and TS parameter annotations, evaluate the resulting plain-JS
   object literal, then `JSON.stringify(spec, null, 2)` — or hand-copy the
   `SPEC` object and convert TS object-literal syntax to strict JSON:
   double-quote all keys, remove trailing commas, resolve any helper
   function calls like `errorRef(...)` to their literal return value).
2. Validate: `node -e "JSON.parse(require('fs').readFileSync('docs/api/openapi.json','utf8'))"` must exit cleanly.
3. Re-upload to readme.io.
