## New finding to put on the page (inventory — the user's „vielleicht ja doch")

Checked in the SCC app repo (StarOrga/Star-Citizen-Companion-App):
- Game.log has `RequestLocationInventory` (which location the player opened the inventory at) and, from the loadout editor, `<UI - LoadoutEditor> … AsyncGetPersonalLocationInventoryId` (docs/features/mobiglas-hints.md). → the log knows **WHERE** an inventory was opened, not **WHAT** is in it.
- The SCC app has an OCR loop (docs/features/ocr-analysis-loop.md): every 3 s, only when SC is foreground + fullscreen, region profiles with regex patterns. → an „Inventar" profile could read the visible item list when you open your local inventory, and an „ASOP" profile could read the ship list at a fleet-manager terminal (with storage location).
- Combined: **Log says where, OCR reads what** → an inventory snapshot per location, refreshed each time you open that inventory; ship storage location from the ASOP terminal. Not continuous, but correct as of your last look. Fallback: manual „liegt in …" via search quick action.

## The single design `hq3` — „HQ in vier Seiten" (motto e.g. „Planen · Jetzt · Bestand")

A Verse-like vertical page of four full-height „Seiten" (scroll sections, snap feel), each a cinematic stage band with a small side index (1–4 dots, labels: Start · Planen · Jetzt · Bestand). Screens = the states the user should judge:

An einem Ort."), then THREE glowing launch steps in a row (1 RSI-Hangar holen → 2 SCC-App verbinden → 3 Ersten Einsatz planen) with progress, and a primary „Los geht's" that starts the tour; „Überspringen" quiet. Use rich CSS (gradients, glows, subtle keyframe animation allowed in round `<style>` but NOT inside screens; respect prefers-reduced-motion).
2. `f1-s2` **Seite 1 · Start** — centred hero exactly like other main pages: kicker, title „Hauptquartier", INSIDE the hero an instrument strip with the newest patch news (only if it touches you: „4.3.1 · S3-Repeater −8 % · betrifft Bounty v3 ›"), then the centred search field (same as Verse/Codex). Under it 3–4 compact „Jetzt wichtig" chips (e.g. „Raffinerie fertig in ARC-L1", „Einsatz Sa 20:00", „2 Dinge im Nachschub liegen in Area18"). Side index dots.
