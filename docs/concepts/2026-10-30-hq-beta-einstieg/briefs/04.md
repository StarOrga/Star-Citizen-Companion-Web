## My resolution of the model (put it in the intro, use it consistently in every mock)
- **Set = was du mitnimmst** (Ausrüstung oder Schiffs-Loadout). **Einsatz = was du tust.**
- Einsätze have TWO shapes, exactly the user's split:
  - **Einzel-Einsatz** — one action gets you what you want. Types: **Abholung** (kaufen/abholen an einem Ort), **Herstellung** (craften, Blueprint vorhanden, Material da), **Auftrag** (eine Spielmission, z. B. eine Uploader-Mission).
  - **Operation** — several game missions/steps in one plan (z. B. Blueprint-Auftrag → Minen → Raffinieren → Transport → Craften), possibly across star systems.
- A Nachschub row now says **„für Set Sanitäter"** (wofür, small) and its **Einsatztyp chip** (Abholung / Herstellung / Auftrag / Teil von Operation …), never „Woher".
- Einsatz buttons are NOT per row anymore: you tick needs (or use the filter), switch to **Schritt-Modus**, see the optimal route, then ONE primary button at the route panel: „Als Einsatz speichern" (becomes Einzel-Einsatz if 1 step, Operation if more). This answers „wirken verloren".

## The planning map — visual encoding (design it carefully, show a compact legend on the map)
- **Shape = Aktion**: ◆ Kaufen/Abholen · ▲ Abbauen/Bergen · ⬢ Raffinieren · ⚙ (or rounded square with cog) Craften · ⚑ Auftrag annehmen/abgeben. One shape per action, nothing else uses shapes.
- **Size = wie viel du dort machst** (number of needs/steps or SCU at that place).
- **Color = welcher Bedarf** (each selected need gets one hue from a small categorical palette that is NOT the accent cyan, not red; matches the need's chip in the list). Status via fill: filled = erledigt, outline = offen, glowing cyan ring = nächster Schritt.
- **Lines**: thin dashed = Reise (you fly empty/personal), thick solid with chevrons = Transport (you carry cargo; thickness ~ SCU). Quantum jumps inside a system as straight lines; **jump points** between systems as an arc through a gate marker.
- **Multiple systems**: Stanton | Pyro | Nyx as side-by-side system panels (or zoomed-out strip) with jump gates linking them; a route can cross systems.
- **Filter** (Komponenten-Filter): chips per need / per Set / per Einsatztyp. **Schritt-Modus** toggle: shows the optimal order for everything in the filter as numbered steps along the route, a step list beside the map (1 Area18 · Abholung ParaMed ×5 → 2 Daymar · Hadanite abbauen → 3 ARC-L1 · raffinieren → 4 Pyro Gateway · … ), totals (≈ Zeit, Sprünge, SCU), Weiter/Zurück through steps, and the primary „Als Einsatz speichern".
