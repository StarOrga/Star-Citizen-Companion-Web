## What round 2 must show

**Four new designs**, each clearly — even excessively — different in how the view hierarchy is operated (the user explicitly asked for more variants). Proposals (refine freely, keep them distinct):

1. **Pfad** — one light breadcrumb-like selector `Außen ▸ Schema ▸ Draufsicht`; each segment is a small dropdown (open state shown on one screen). Description named „Akte“ as a level-2 option. Ownership as quiet text in the title row („In deinem Hangar · 1× ▾“).
2. **Filmstreifen** — no switcher row at all: a row of small thumbnail cards at the bottom-left of the table (mini previews: 3D, Einfach, Oben, Seite, Front | Innen | Akte, Lackierung), grouped by thin dividers into Außen / Innen / Mehr. Ownership as a badge in a table corner.
3. **Achsen** — two tiny independent switches `Außen | Innen` and `3D | Plan | Akte`, plus a CAD-like orientation cube in the table corner for Oben/Seite/Front (Plan's default = Einfach). Lackierung and model picker under the name.
4. **Ein Menü** — a single compact control „Ansicht: Außen · Plan · Einfach ▾“ that opens a grouped two-column menu (Außen: 3D, Einfach, Draufsicht, Seitensicht, Frontsicht | Innen: Decks | Mehr: Akte, Lackierung). Minimal head.
