## Project facts (from the code)

**Hub scroll today (what the transition should echo).** The shell scene is fixed behind
the page; its planet layer translates up with the page via a scroll-driven animation
(`animation-timeline: scroll(root)`), so on scroll the planet slides up and out of view.
On `/verse` the hub's own big planet sits in the bottom third of the stage and simply
scrolls on under the footer; the hub columns (News | Patches | Galerie) sit box-less on
the planet's night side. No fade of hub content. → The transition = the same vertical
camera move (scene slides, planet moves away / towards the target), not a new effect.

**Patches page today (`/verse/patches`), top to bottom:**
1. Header (title + subtitle).
2. KPI strip, five tiles with value + label + small bar sparkline (ok/warn/bad):
   „Patch-Linien im Archiv“, „letzte Testphase (n Tage)“, „zwischen Hauptpatches
   (Median, n Tage)“, „zwischen Hotfixes (Median, n Tage)“, „zuletzt stabil gelandet“.
3. Panel „Bereit für {line}“: checklist of toggle steps + progress line (n von m).
4. Panel „Kometen-Tipp: Wann geht {line} live?“: date input, submit, then your tip and
   the community median.
5. Patch board:
   - Prediction monitor: „live seit X Tagen“ / „im Test seit X Tagen“ tiles, cadence
     state (im Takt / üblich / überfällig), next version with ETA date.
   - Stability history (stability per patch over all time).
   - Search field with result summary.
   - The stack of patch cards (= the timeline): per line a status chip (next / evocati /
     ptu / live / superseded), line label, item entries, stability badge. Each entry row:
     title, version tag, stage tag (Live / PTU / Evocati), hotfix tag, stability chip,
     time, hits/points count, external RSI link ↗. A click opens a dossier overlay
     (cycle chart, cadence).
   - „Ältere“ collapsible.
   The round-1 mock lacked: prediction monitor (live/test since, ETA, cadence state),
   stability history + stability chips, search, the real entry fields, the dossier.

**Sternkarte today (`/verse/explorer`), top to bottom — keep this order:**
- Sky backdrop.
- Header bar: h1 „Sternbild {patch}“ (→ becomes „Sternkarte {patch}“), subtitle, shape
  name, patch chips (switch patch), progress lit/total, actions: Wallpaper exportieren,
  „Meine Sternbilder“ toggle (→ „Meine Sternkarten“), link to gallery, „mehr“ side
  sheet, tour button.
- The star dome (the map itself) — or, in mine mode, the list of own maps.
- Below the map, side by side: comet track (Kometen-Tipp / prediction track) and guess
  track (community tips).
- Series strip (all patches as a strip).
- Right side sheet „mehr“.
The big opaque box is `.map`: near-black background (92 % bg-0), 1 px border, 14 px
radius, height = viewport − top bar. That box goes; the scene shows through.

**Terms today:** „Sternkarte“ (page title), „Sternbild“ in many strings (map title,
empty state, guess kind, „Meine Sternbilder“, „Community-Sternbild“), „Kartograph ·
Rang n“, „Kartograph-Abzeichen“. All „Sternbild“ → „Sternkarte“.

**Kartograph badge today:** an entry „Kartograph-Abzeichen“ in the account dropdown of the
shell header (links to `/badge/kartograph` when unlocked, else to the Sternkarte); also
found via the header search. It leaves the profile menu.

**Apps today:** SCC App: only a status chip in the shell header with „Companion-App
herunterladen“ (Windows installer). Starscape: download menu on the Starscape page, a
one-time promo popup, and on the gallery (mini bar / hero). Data Uploader: collaborators
only, on the codex landing — not part of the public apps menu (it is admin/collaborator,
red-marked rule: elevated-access entries use the hot accent).

**Project UI rules that the mocks must respect:** one page frame (no page sets its own
max width; 1280 px, 1600 px on QHD); one page header (crumbs, eyebrow, the only h1,
subtitle, aside/actions slots); red accent only for elevated-access surfaces; a worse
comparison value uses the warning colour, never danger; navigation targets are real
links; no native tooltips/selects; prefers-reduced-motion → crossfade only.
