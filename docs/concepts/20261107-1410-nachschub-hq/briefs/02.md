## The model as I read it now (topic 1 confirms it with ONE verify, then asks the open model questions)

- Wunschliste = shopping cart, **with quantity** (20 Rattler), for everything incl. material. Reached from everywhere (Codex, Suche, Holo, Blaupause „Material ×N auf die Wunschliste“, grouped under the blueprint / crafted item). Presented as a cart popup.
- Nachschub = a **named package** built in HQ → Planen by taking items (or part quantities) from the Wunschliste. Up to **7 packages** planned ahead. Each package has **1–x Einsätze** (Missionen, Bergbau, Handel …). A package is planned as a whole — to plan less, move less from the wishlist.
- HQ Jetzt runs the Einsatz bundle of exactly **one** package and always shows what it is for.
- A line closes only on auto-detection (inventory higher than before) or a manual tick — never by time („manchmal spielt man länger nicht“).
- „Nachschub leeren“ (any time): open lines go back to the Wunschliste (quantity counted up there).
- Bestand (rare umbrella word) = Inventar · Hangar · Sammlung. Sammlung = Blaupausen, Ruf, News, Galerie-Bilder (anything collected). Shortcuts: an item can go straight to Bestand; news/gallery go straight to Sammlung (no wishlist, no Nachschub).
- „Nachholen“ on a Bestand row = put it on the Wunschliste.
- AI names: package = summary of what you get, Einsatz = what you must do, within character limits.
