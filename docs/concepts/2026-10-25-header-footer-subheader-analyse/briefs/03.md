  „Die Suche ist hier ja super platziert, könnte diese nicht zum Subheader werden beim Scrollen und
  auf anderen Seiten schon sein?“ ⇒ NEW RULE: there is ONE morph bar for all page types. On a
  cinematic main page the search line sits in the stage; when you scroll, it morphs INTO the bar
  (it becomes the header/subheader). On every other page the bar already IS search + crumbs (+ tool
  drawer on tool pages). No per-type header modes any more — rewrite the Regelwerk table for that

- Breiten: **„Spuren plus Zusatzspalten“** chosen (full / wide / narrow 720–1040 px, extra
  columns from ~1600/2200 px instead of stretching). Others discarded.
- Handy: **Einmal-Code per QR (serverseitig getauscht) + Magic Link per E-Mail als Ausweg** both
  included; desktop approval, passkey, refresh-token QR discarded.

- Overlays: one frame for three overlays, URL per overlay, anchor list per long page — included.
- Zuordnung (mapping `seitentypen2`): no changes from the user — carry its spec as proposal = the
  user's submitted assignment (read the frozen spec's `submitted.cells` in rounds/02.html), or drop
  the mapping from round 3 and state "Zuordnung bestätigt" in the summary view. Prefer dropping it
  and listing it as confirmed.
