# Common rules for every Wave 1 implementer (Kamera-Welt)

1. **Parent branch:** `claude/main-pages-transition-animations-6e2170` (tip `659a70d0` or later). You run in your own git worktree. First: `git log --oneline -1` — if `659a70d0` is not an ancestor (`git merge-base --is-ancestor 659a70d0 HEAD`), run `git merge --no-edit claude/main-pages-transition-animations-6e2170`. Work on your own branch `kw/<your-slug>` created from there. Do NOT push to the parent branch, never touch main.
2. **Dependencies:** run `npm ci` in your worktree once (never junction node_modules from another checkout). Node 24.
3. **Binding spec:** read `docs/concepts/20261109-1752-kamera-welt/briefs/implement.md` completely (verbatim user quotes + checklist), `parity.md`, and the mock fragments `rounds/05.html` (design `welt5`, current) and `rounds/04.html`. *Read every listed round fragment; its markup, CSS and keyframes are the spec, not a reference. Report each checklist line you own as built with evidence, or as not built with the reason.* Mocks are 1600×900 screenshots in `cqw`; translate timings/easing/order faithfully, positions to the real DOM.
4. **Repo rules (root CLAUDE.md):** standalone + signals + OnPush; every user-facing string via ngx-translate (`public/i18n/{de,en}.json`); navigations are real anchors; actions via `scAction`; no native dialogs/`title`/`<select>`; errors via `toErrorKey`; logging only `core/log.ts`; phones: `--sc-float-bottom`, `dvh`. All new behaviour stays behind the **shell beta** (`BetaService.isEnabled('shell')`) unless the brief says otherwise. `prefers-reduced-motion`: short crossfade (~420 ms flights, simple fade elsewhere), never a fly. Animate only `transform`/`opacity`/`clip-path`/`filter` on small layers; no layout-thrashing reads in animation frames; no `setInterval` inside the Angular zone (use `runOutsideAngular`).
5. **File ownership:** you own ONLY the files listed in your task. Never edit `src/styles.scss` unless your task says you own it — put styles in your component SCSS or a new partial under your owned folder. If you truly need a change in a file you do not own, do not make it: report it in your result as a handoff note (file, exact change, why).
6. **Verification before you report:** `npm run typecheck`, `npm run lint` on your files, `npm run build` (templates are only checked by the build), and the Vitest specs of your area (`npm test -- --include=app/<area>/**/*.spec.ts`; run the test runner in its own Bash call, never chained with `&&`). Update/extend specs for changed behaviour. For visible work: `ng serve --port <your port> --host 127.0.0.1` in the background, then Playwright (`channel: 'msedge'`, headless, beta via `localStorage.setItem('sc.beta', JSON.stringify({verse:true,codex:true,shell:true}))`, signed-in via `scripts/playwright/test-session.cjs` if the route needs auth — never read `sc.auth`, the test account is an admin on production data: no irreversible actions) at 1600×900 and 390×844; save sampled animation frames (pause `document.getAnimations()` at set `currentTime`s) to `tmp/kw-<slug>/` (untracked). Stop your dev server when done (only your own PID).
7. **Commits:** *"Commit `wip(<scope>): <what>` on your branch after every green sub-step and at the latest every ~10 file-changing tool calls — an agent cut off by a usage limit never gets to commit at the end. Only on your own sub-branch or the session's branch — never above it: while the session is on a feature branch, never on main, master or the default branch."* Final commit `feat(<scope>): …` with body, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (or your own model). Push your branch `kw/<slug>` to origin.
8. **Interaction:** Autonomous — make reasonable decisions inside your scope; do not ask the user. **Budget:** `[budget] Ultra · week 40% → free`. **Effort ceiling:** ~30 tool calls of real work beyond setup; on hitting it, commit and report the scope-cut.
9. **Done when:** every checklist line you own is built (or reported not built with reason), typecheck + lint + build + your area's specs are green, branch pushed. **Return** exactly: branch name + head SHA; an acceptance table `| line | done/partial/not done | evidence (file:line, spec, frame path) |`; handoff notes for files you did not own; anything you could not verify.
