### Topic t2-cons „Konsistenz und Revision“ (answers the general comment)
4. `d2-base` — single. Situation: correction numbers + style finding. „Welcher Stil prägt die deutsche Übersetzung?“ Options: ★ `community` „Der Hybrid-Stil des Pakets ist die Basis“ (94 % text already in it; CIG terms only where the pack is outdated or the judge finds a real error) · `cig` „CIGs offizielle Begriffe sind die Basis“ (glossary forces CIG terms; ~10 000 pack lines would be rewritten → AI cost and the pack's look disappears) · `perkey` „Jeder Key frei nach Qualität“ (user's original idea; mixes both systems). 5. `d2-arbiter` — single. Builds on the user's d-order note (KI entscheidet pro Key, unsicher → Admin). „Wie entscheidet der Schiedsrichter pro Key?“ Options: ★ `guarded` „Erst Regeln, dann KI-Paarvergleich mit Konsistenz als Pflichtkriterium“ — deterministic pre-filter (identical modulo punctuation → no conflict; placeholder/QA fail → that side loses; stale hash → that side loses; glossary violation → that side loses), then pairwise LLM comparison shown in both orders (position bias), consistency with the base style and glossary as hard criterion, disagreement between the two orders or low confidence → Karteikarte · `plain` „Jeder Konflikt direkt an die KI“ (simpler, ~same cost, but no bias control) · `fixed` „Feste Reihenfolge Admin > CIG > Community > KI“ (round-1 choice without the note). Rec `guarded`. L3: cost ≈ 2 USD Haiku / 7–8 USD Sonnet once for DE.
6. `d2-revise` — single. The scientific mechanism for „Konsistenz meistens, aber alte Einträge dürfen sich ändern“. „Wann darf ein bestehender Eintrag ersetzt werden?“ Options: ★ `hysteresis` „Nur bei klarem Vorsprung, dann überall auf einmal“ — a challenger replaces the incumbent only when it wins the pairwise judgement in both orders AND (for a glossary term) has more evidence than the incumbent by a margin; then the change propagates to every string using the term (`needs_retranslate`), never one string alone; a per-release change budget (e.g. max 2 % of a language's strings) keeps churn low; admin-locked entries never move · `freeze` „Nur der Admin ändert bestehende Einträge“ · `latest` „Die neueste Quelle gewinnt immer“ (flip-flops between sources). Rec `hysteresis`. L3 cite the grounding briefly and honestly: MQM error typology (Lommel et al. 2014; Freitag et al. 2021) counts inconsistency and terminology as errors; LLM-as-judge shows position bias, so compare in both orders (Zheng et al. 2023); fuzzy-match examples from one's own TM improve LLM translation (Moslem et al. 2023); hysteresis/margin rule = standard way to stop oscillation in ranking systems. Don't overclaim („wissenschaftlich bewiesen“) — say „gestützt auf“.
