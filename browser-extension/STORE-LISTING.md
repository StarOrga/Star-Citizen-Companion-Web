# Chrome Web Store listing — Verse Companion Hangar Import

Paste these texts into the Chrome Web Store developer dashboard (Store listing
tab). The short description is the manifest's `extDescription`
(`_locales/*/messages.json`, max. 132 characters) and updates with the package.

## Name

- EN: Verse Companion — Hangar Import
- DE: Verse Companion — Hangar-Import

## Detailed description (EN)

Verse Companion – unofficial fan tool for Star Citizen.

This extension copies the ship list from your own RSI hangar page
(robertsspaceindustries.com/account/pledges) into your Verse Companion hangar.

How it works:
- It only runs on your own RSI hangar page and on the Verse Companion site.
  Nowhere else.
- It only reads the page while you have it open yourself, signed in as usual.
  It never signs in for you and never reads cookies, passwords or tokens.
- The ship list stays in this browser and is handed to a Verse Companion tab.
  Nothing is written to your account until you tick the ships and confirm them
  there.
- The extension itself sends nothing to any server.

## Known risk (for the maintainers, not the listing)

RSI's Terms of Service (section IV) forbid bots and scrapers. The extension
reads only the page the user has open, on the user's action, and automates no
requests beyond loading the user's own hangar pages; it is still an automated
reader of an RSI page. Keep it user-initiated and local.
